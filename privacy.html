JACK MEOW / PRIVACY

Privacy, plainly.

This page covers the Jack Meow public website.

No account required

You can read this static website without creating an account. The website does not include analytics, tracking scripts, newsletter forms, or cookies set by its own code.

Application credentials

The website itself does not collect Jack Meow application credentials. Application credentials are configured locally by the user; do not send credentials or other secrets to the website contact address.

Hosting and third-party services

Third-party infrastructure, including hosting and CDN services, may process standard request metadata such as IP addresses, requested URLs, and browser information according to their own policies. This website is intended to be hosted on Cloudflare Pages. See Cloudflare’s privacy policy.

Following an external link, such as the Snap Store link, takes you to a service with its own privacy practices. This website’s privacy information does not describe data processing by services you configure in the Jack Meow application.
